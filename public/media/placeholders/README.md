## Производные

- Основная: 1200 × 800, WebP, качество 84, центральное кадрирование 3:2.
- Узкий экран: 480 × 320, WebP, качество 84.
- Сжатие выполнено из скачанных оригиналов, а не из производной.
- Оригиналы лежат вне `public`: `portfolio-planning-audit/media-originals/`; в публикацию не включаются.
- Ни один WebP не превышает 150000 байт; все декодируются.
- Для `srcset` используйте два файла одной пары; у `img` укажите width/height и описательный `alt`, не выдающий фото за проектный артефакт.
